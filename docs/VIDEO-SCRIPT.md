# 录屏脚本 · cursor-manager 介绍视频

> ## 先看这里：有两条路
>
> **A. 自动生成 —— 不需要录屏、不需要剪辑软件**
>
> ```bash
> make demo          # → demo/cursor-manager-demo.mp4，约 56 秒
> make demo-list     # 只列场景和时长
> ```
>
> 画面全部来自**真实数据**：终端场景跑的是真命令、渲染的是真输出（含 ANSI 颜色）；
> 动画光标是从你已安装的主题里真解码出来的（Xcursor → 逐帧 RGBA）；
> 导入场景用临时 `XDG_DATA_HOME`，**不碰你的真实配置**。
> 1920×1080 / 30fps / 无人值守。
>
> 适合：快速出一版能发的、或者当真人录制的**粗剪素材 / 分镜参考**。
>
> **B. 自己录 —— 下面这份脚本**
>
> 真人旁白 + 真实 GUI 操作，效果更好，但要录制和剪辑。
>
> 两条不冲突：先跑 A 出个能发的版本，想精修再走 B。

**目标观众**：用 Linux + Wayland（niri / Hyprland / Sway 等）的人，尤其是被"改了光标主题却没反应"折磨过的。
**时长**：主版本约 4 分钟。文末有 60 秒短视频版。
**形式**：屏幕录制 + 旁白。不需要出镜。

---

## 一、录制前准备

### 1. 让痛点场景可复现

开场要用那个**"装了也不会生效"的主题**当反面教材。你机器上正好有一个：

```
/usr/share/icons/Kinomoto‑Sakura     ← 缺 cursors/ 子目录，永远不会生效
```

先确认 `cursor-manager --list` 能看到它被标红 ✘：

```bash
cd ~/code/linuxcursettingtool
./cursor-manager --list
```

### 2. 准备要导入的包（放在显眼位置）

```bash
ls -la ~/Downloads/初音未来+鼠标指针.zip        # 10 MB，导入约 0.3 秒
ls -la ~/.icons/.disabled-20261010/"KINOMOTO SAKURA"   # 大包，导入约 6.6 秒
```

**两个都准备**：小包用来说明"识别角色"，大包用来让进度条有存在感。

### 3. 清一个干净的开场状态

```bash
# 先切回系统默认，这样"换了没反应"的对比更明显
./cursor-manager apply Adwaita 24
```

### 4. 录制参数建议

| 项 | 建议 |
|---|---|
| 分辨率 | 1920×1080，或 2560×1440 |
| 帧率 | 30 fps 够（光标动画在 24px 下不抖） |
| 画面区域 | **尽量全屏**。光标很小，观众需要看清它 |
| 鼠标 | Wayland 下 OBS 走 xdg-desktop-portal 抓屏，**真实光标会被录进去** —— 演示时手别抖 |
| 缩放 | 讲代码/终端时后期放大到 140%，讲界面时保持 100% |
| 浏览器 | 提前打开仓库页和 Release 页，别在录的时候等加载 |

### 5. 关掉会干扰的东西

通知、聊天软件、其他窗口。**录屏会露出版权素材**，`~/Downloads` 里那些主题包的预览图（动漫角色）尽量别进画面。

## 三、完整旁白稿

> 「」内是念出来的词。其余是动作提示。

### 0:00 · 钩子

> 「我把光标主题装好了，配置文件也改了，会话也重启了。结果——还是这个白箭头。没有任何报错，也没有任何提示，就好像我的配置根本不存在。」

**动作**：鼠标在空桌面上慢慢划过，让白箭头清晰可见。停两秒。

> 「如果你在 Linux 上折腾过鼠标光标，这场景应该很熟悉。问题不在你，在 Wayland。」

### 0:20 · 根因

**动作**：切到终端，`cd ~/code/linuxcursettingtool`，跑 `./cursor-manager --list`。

> 「Wayland 下换光标，所有程序都遵守同一条硬规则：主题目录里必须有一个 `cursors/` 子目录。少这一层，程序会**静默忽略**你的主题，回落到系统默认——不报错，不提示。」

**动作**：指到那一行红色的 ✘（`Kinomoto‑Sakura 缺少 cursors/ 子目录`）。

> 「这个工具第一步就是把这种"静默失败"变成看得见的红叉。你看，这个主题就是坏的——它少了 `cursors/` 那一层。」

### 0:50 · 为什么要写 6 个地方

**动作**：切到 README 里那张表（`为什么做这个` 一节），或者直接讲。

> 「更麻烦的是，Wayland 下**没有全局光标设置**。niri 自己画的光标读一份配置，GTK 应用读另一份，Firefox 和 Electron 走环境变量，XWayland 的程序看 `.Xresources`，走 GSettings 的又看 dconf。一共六个地方，漏掉任何一个，那一类程序就还是白箭头。」

> 「所以经常出现"桌面上的光标变了，但一进 Firefox 就变回去"。」

### 1:10 · 界面导览

**动作**：跑 `./cursor-manager` 打开图形界面。

> 「这是 cursor-manager，我用 GTK4 写的。左边是扫描到的所有主题，✔ 是可用的，✘ 是布局坏掉的。」

**动作**：点一个动画主题（比如初音）。右边的网格开始动。

> 「右边这个预览是我自己解码 Xcursor 二进制格式渲染出来的。**普通图片查看器打不开这种文件**——它不是 PNG，是一套自己的容器格式。」

**动作**：让动画跑一会儿，别急着切。

> 「所以你能直接看到每个光标长什么样、动起来是什么效果，而不是先装上、再回桌面看、不满意再换。」

### 1:55 · 细节

**动作**：鼠标悬停在某个格子上，出现 tooltip。

> 「悬停能看到这个光标的所有别名。这个很重要——`pointer`、`hand2`、`pointing_hand` 其实指向同一张图，但不同程序会查不同的名字，漏一个就有一类程序不生效。」

**动作**：点右上角「实际大小」。

> 「这里可以切成实际尺寸 1:1 看。毕竟你最终用的是 24 像素那么大的东西，放大看好看不代表实际清楚。」

### 2:25 · 一键应用

**动作**：选好主题，点「应用到系统」。弹出报告窗口。

> 「点一下应用，它会把六个配置点全写一遍——niri 的配置、DMS、GTK3、GTK4、XWayland 的 `.Xresources`，还有 GSettings。」

**动作**：镜头停在这个报告窗口上。

> 「每一项都会告诉你写了什么。不想真改的话，命令行有 `--dry-run`，只报告不落盘。」

### 2:50 · 导入 Windows 光标包（**核心卖点，多给时间**）

**动作**：点「导入主题」→「从压缩包 / 光标文件导入…」。

> 「最有意思的功能是这个：**导入 Windows 的光标包**。」

**动作**：选 `~/Downloads/初音未来+鼠标指针.zip`。导入结果弹窗出来（约 0.3 秒，几乎瞬间）。

> 「Windows 的光标包是一个 zip，里面一堆 `.ani` 文件加一个 `.inf` 安装脚本。」

**动作**：指着结果弹窗里的「角色映射：包内 .inf（官方数据）」。

> 「这个 `.inf` 是关键——里面直接写着微软官方的角色映射：`pointer` 对应哪个文件、`work` 对应哪个。这是权威数据，比按文件名瞎猜可靠得多。所以十七个角色**全部**一次识别对。」

**动作**：指着「17 个光标 / 113 个别名」。

> 「它还会自动补上那一百多个别名，并且从原始分辨率降采样出多个尺寸档。这个包是 32×32 的，很快；我换个大包给你看。」

**动作**：再导入 `~/.icons/.disabled-20261010/"KINOMOTO SAKURA"`（256×256，146 帧）。

> 「这个是 256×256 的，十七个角色一共一百四十六帧，要转大概七秒。」

**动作**：**让进度条跑完**，别剪掉。

> 「注意别以为越慢越差——它是从 256×256 降采样出 24 到 96 五个尺寸档，比升采样清晰得多。」

### 3:40 · 安全设计

**动作**：选中一个系统主题（比如 Adwaita），把鼠标停在灰色的删除按钮上，出现 tooltip。

> 「删除是唯一不可逆的操作，所以加了四道闸门。系统目录里的主题不让删；**正在用的那个也不让删**——删完所有程序会静默回落到默认，正是这个工具要防的坑。而且默认是移进回收站，不是真删。」

**动作**：菜单 → 检查更新。

> 「检查更新只在手动点的时候联网，查到了也不会自动装。这个工具会写你的配置文件，自动替换出问题的代价太高。」

### 4:00 · 收尾

**动作**：切到浏览器，仓库页。

> 「项目在 GitHub 上，MIT 协议。Arch 用户可以直接下 `.pkg.tar.zst` 用 pacman 装；其他发行版有源码包和 wheel。README 里写了三种安装方式。」

**动作**：滚到"平台支持"那张表。

> 「顺便说清楚：这工具在 niri + DMS 上是完整验证过的，GNOME、KDE、sway 这些平台支持部分功能，README 里有详细表格。」

> 「链接在简介里。如果你也被 Wayland 的光标折磨过，试试看。」

## 四、演示命令速查（可直接复制）

> **顺序有依赖**：`apply Miku` 和 `remove Miku` 都要等上面的导入先跑完。
> 导入命令带 `--overwrite`，重复执行是安全的（之前删过会自动重建）。

```bash
cd ~/code/linuxcursettingtool

# ① 开场：看那个坏掉的主题（红色 ✘）
./cursor-manager --list

# ② 切回系统默认，让开场的"白箭头"成立
./cursor-manager apply Adwaita 24

# ③ 先把演示要用的主题导进来（可重复执行）
./cursor-manager --import ~/Downloads/初音未来+鼠标指针.zip --name Miku --overwrite

# ④ 打开界面
./cursor-manager
```

**界面里要操作的**：

- 左侧点主题 → 看动画预览
- 悬停格子 → 看别名
- 「导入主题 ▾」→「从压缩包 / 光标文件导入…」→ 选 `~/Downloads/初音未来+鼠标指针.zip`
- 再导入一次大包 → 选 `~/.icons/.disabled-20261010/"KINOMOTO SAKURA"`（有进度条，约 7 秒）
- 「应用到系统」→ 看六项报告
- 选中 `Adwaita` → 看删除按钮变灰 + tooltip 说明
- ≡ 菜单 →「检查更新…」

**命令行也能干同样的事**（可单独录一段）

```bash
./cursor-manager apply Miku 24 --dry-run       # 只报告不写盘
./cursor-manager remove Miku --dry-run         # 看会删什么、多大
./cursor-manager --check-update
```

> 上面的 `--dry-run` 一定要留着。真删除会把主题移进 `~/.local/share/Trash/`，
> 录完想恢复得手动搬回来。

## 五、录制前自检

正式开录前跑一遍，确认所有演示素材都在位：

```bash
cd ~/code/linuxcursettingtool

echo "— 待导入的包 —"
for f in ~/Downloads/初音未来+鼠标指针.zip \
         ~/.icons/.disabled-20261010/"KINOMOTO SAKURA"; do
  [ -e "$f" ] && echo "  ✓ $f" || echo "  ✘ 缺: $f"
done

echo "— 那个坏掉的主题（开场要用）—"
./cursor-manager --list 2>&1 | grep -q "✘" && echo "  ✓ 有被标红的主题" || echo "  ✘ 没有可展示的坏主题"

echo "— 演示用的主题是否已导入 —"
./cursor-manager --list 2>&1 | grep -q "Miku" && echo "  ✓ Miku 在" \
  || echo "  ! Miku 不在 —— 先跑第四节的 ③"

echo "— 版本 / 网络 —"
./cursor-manager --check-update 2>&1 | head -2
```

三项都 ✓ 就可以开录了。

## 七、录制小贴士

**几个容易翻车的点：**

1. **光标太小**。24 像素在 1080p 录屏里几乎看不清。讲光标本身时，前期放大到 300% 再切回全屏。
2. **动画要留时间**。预览网格的动画 8～20 帧、每帧 150 毫秒，一个循环 1～3 秒。切过去之后停够两秒再开口。
3. **别在录的时候导入大包**。256×256 的包要 6.6 秒——这时间正好可以讲"为什么要降采样"，但**要提前写好词**，不然就是干等。
4. **终端字号调大**。`Ctrl + =` 调终端字号，1080p 下建议 16～18pt。
5. **先跑一遍完整流程再正式录**。尤其是导入和删除这两步，确认你要演示的包确实存在。
6. **隐私**。`~/Downloads` 里可能有别的东西；录屏前把无关窗口和文件列表收起来。

**如果录 niri 桌面**：建议用 `niri msg action screenshot-screen` 或直接 OBS 的 Screen Capture (PipeWire)。niri 24.05 之后走 xdg-desktop-portal，光标会被正常录进去。
